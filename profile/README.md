# WebberZone

[![WordPress Badge](https://img.shields.io/badge/WordPress-black?logo=wordpress&logoColor=white&style=for-the-badge)](https://profiles.wordpress.org/webberzone/) [![X Badge](https://img.shields.io/badge/X-black?style=for-the-badge&logo=x&logoColor=white)](https://x.com/WebberZone) [![Facebook Badge](https://img.shields.io/badge/Facebook-white?style=for-the-badge&logo=facebook&logoColor=blue)](https://www.facebook.com/WebberZone) [![LinkedIn Badge](https://img.shields.io/badge/LinkedIn-blue?style=for-the-badge&logo=linkedin&logoColor=white)](https://uk.linkedin.com/company/webberzone)

I'm [Ajay D'Souza](https://ajaydsouza.com/). I've been blogging since 2003 and building WordPress plugins since 2005. WebberZone is where those plugins live.

The plugins help visitors find more of your content: related posts, popular posts, on-site search and a knowledge base. Each has a free version on WordPress.org, and most have a Pro version with more features.

For the full list, including utility plugins, developer libraries and retired projects, see [webberzone.github.io](https://webberzone.github.io).

## Plugins

| Plugin | What it does |
|---|---|
| [Contextual Related Posts](https://github.com/WebberZone/contextual-related-posts) | Shows posts related to the one being read |
| [Top 10](https://github.com/WebberZone/top-10) | Counts post views and displays your popular posts |
| [Better Search](https://github.com/WebberZone/better-search) | Replaces the default WordPress search with relevance-ranked results |
| [Knowledge Base](https://github.com/WebberZone/knowledgebase) | Builds a knowledge base or FAQ section |
| [WebberZone Snippetz](https://github.com/WebberZone/add-to-all) | Adds HTML, CSS and JavaScript snippets to your site |
| [Image Optimizer](https://github.com/WebberZone/webberzone-image-optimizer) | Converts your media library to WebP and AVIF |
| [Link Warnings](https://github.com/WebberZone/webberzone-link-warnings) | Warns visitors when a link opens a new window or leaves your site |
| [Code Block Highlighting](https://github.com/WebberZone/webberzone-code-block-highlighting) | Adds Prism syntax highlighting to the Code block |

[Auto-Close](https://github.com/WebberZone/autoclose) and [Followed Posts](https://github.com/WebberZone/where-did-they-go-from-here) are in maintenance mode. They get compatibility and security fixes, but no new features.

- [Code library](https://webberzone.github.io/code-library/): snippets for extending WebberZone plugins
- [Settings API](https://webberzone.github.io/Settings_API/): the tabbed settings class the plugins use
